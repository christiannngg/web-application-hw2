# HW2 Assignment Web. Application and Development

Wordle game + 2 additional new features

## Feature 1

Time Attack Mode: Players race against a countdown clock (e.g., 60 seconds) to solve the word. Every correct letter adds a few bonus seconds to the clock.

## Feature 2

Custom Word Lengths: Allow users to toggle between 4-letter, 5-letter, or 6-letter word grids to adjust the difficulty to their liking.
